# 📞 Callbot: ИИ звонит за тебя

Пишешь в Telegram номер и задачу, например «+380671234567 Забронируй столик на двоих на завтра 19:00 на имя Алексей».
Бот сам звонит, разговаривает голосом (Gemini Live), слушает собеседника и добивается цели.
Когда нужно выбрать (время, столик, услугу), он присылает тебе кнопки. Если за 10 секунд ты не ответил, выбирает сам.
В конце приходит итог: о чём договорились.

## Как это устроено

```
Ты (Telegram) ──► бот ──► Twilio звонит абоненту (на экране у него твой номер)
                              │  живой звук
                              ▼
                       Gemini Live (слушает и говорит голосом)
```

**Почему Twilio, а не «прямо с телефона».** Обычное приложение на Android/iPhone не может подать голос нейросети
внутрь GSM-звонка: система не даёт доступа к звуку разговора (нужен root и всё равно работает плохо).
Поэтому звонок идёт через Twilio, а твой мобильный номер подтверждается там как **Caller ID**,
так что абонент видит **твой номер**. Если он перезвонит, попадёт на твой телефон.

## Что понадобится

| Что | Где взять | Цена |
|---|---|---|
| Telegram-бот | @BotFather → `/newbot` → токен | бесплатно |
| Ключ Gemini | https://aistudio.google.com/apikey (вход через Gmail) | есть бесплатный лимит |
| Twilio | https://twilio.com → Account SID + Auth Token | пробный баланс, дальше поминутно |
| Сервер с публичным адресом | ngrok на своём компьютере или Railway/VPS | бесплатно / недорого |

## 🆓 Бесплатно: Render (всё с телефона, без карты)

1. Открой ссылку: https://render.com/deploy?repo=https://github.com/dmitriy2403iskan-star/calls
2. Войди через GitHub и разреши Render доступ к репозиторию `calls`.
3. Заполни поля: `TELEGRAM_BOT_TOKEN` (от @BotFather), `GEMINI_API_KEY`, ключи Twilio
   (если их пока нет, оставь пустыми и добавь потом в Environment). Нажми **Deploy Blueprint**.
4. Через 3–5 минут напиши боту `/start`.

Бесплатный сервер засыпает через 15 минут без сообщений, а первое сообщение после сна обрабатывается около минуты.
Диск на Render стирается во время сна, поэтому постоянные настройки храни в Render → Environment.
Изменения через `/set` действуют только до сна, и бот сам подскажет, что куда добавить.

## 🚀 Запуск на Cloudflare (платно, $5/мес) (всё с телефона)

Бот работает в Cloudflare Containers. Контейнер засыпает, когда им никто не пользуется (за сон деньги не берут),
и сам просыпается от твоего сообщения в Telegram. Первый ответ после сна приходит через несколько секунд.
Нужен тариф **Workers Paid** ($5 в месяц).

1. **Тариф.** dash.cloudflare.com → Workers & Pages → Plans → **Workers Paid**.
2. **Создать Worker из GitHub.** Workers & Pages → **Create** → **Import a repository** → GitHub →
   разреши доступ → выбери репозиторий `calls` → **Deploy** (команду деплоя оставь `npx wrangler deploy`).
   Первая сборка идёт несколько минут.
3. **Токен бота.** Открой Worker `calls` → Settings → **Variables and Secrets** → Add →
   тип *Secret*, имя `TELEGRAM_BOT_TOKEN`, значение: токен от @BotFather → Deploy.
4. **Разбудить бота.** Открой в браузере адрес Worker'а (`https://calls.<твой-поддомен>.workers.dev`).
   Должно появиться «✅ Бот-звонилка работает». Адрес для звонков (`PUBLIC_URL`) бот возьмёт сам.
5. **Telegram.** Напиши боту `/start` (ты станешь владельцем), потом:
   - `/set GEMINI_API_KEY …`
   - `/set TWILIO_ACCOUNT_SID …` и `/set TWILIO_AUTH_TOKEN …`
   - `/mynumber +380…`, чтобы бот звонил с твоего номера
   - по желанию `/set OWNER_NAME Имя`

Настройки, заданные через `/set`, сохраняются в Cloudflare и не пропадают, когда контейнер засыпает.
Любой ключ можно задать и как Secret в дашборде (шаг 3), но значение из `/set` имеет приоритет.
Каждый `git push` в `main` автоматически пересобирает бота.

## Установка на свой сервер / компьютер

### 1. Twilio: подключить свой номер
1. Зарегистрируйся на twilio.com и скопируй **Account SID** и **Auth Token** с главной страницы Console.
2. После запуска бота напиши ему `/mynumber +380XXXXXXXXX` (свой мобильный).
   Twilio позвонит тебе, ты введёшь на клавиатуре код из чата, и бот сам начнёт звонить с твоего номера.
   (Вручную то же самое делается в Console: Phone Numbers → Verified Caller IDs.)
3. **Voice → Settings → Geo permissions**: включи страны, куда будешь звонить (например, Украину).
4. На пробном аккаунте Twilio звонит только на подтверждённые номера и в начале проигрывает свою фразу.
   Чтобы звонить куда угодно, пополни баланс (Upgrade).

### 2. Запуск
```bash
cp .env.example .env        # заполни значения
pip install -r requirements.txt
python -m app.main
```
Сервер слушает порт 8000. Ему нужен публичный https-адрес:
```bash
ngrok http 8000             # скопируй https://….ngrok-free.app в PUBLIC_URL
```
(или задеплой Dockerfile на Railway/Render/VPS и укажи их адрес).

### 3. Telegram
Открой своего бота и нажми `/start`. Первый, кто нажмёт `/start`, станет владельцем, остальных бот игнорирует.

## Пользование

- **Звонок:** `+380671234567 Узнай, есть ли запись на стрижку в субботу после 12, запиши на имя Алексей`
  (номер можно писать как `067 123 45 67`, `(044) 222-33-44`, `+380…`).
- **Вопросы от бота:** приходят с кнопками. Можно нажать кнопку, ответить текстом или нажать «🤖 Реши сам».
- **Подсказка во время звонка:** просто напиши в чат («скажи, что нас будет четверо»), бот учтёт это сразу.
- **Положить трубку:** кнопка под сообщением «Звоню…» или `/hangup`.

### Настройки прямо из Telegram
- `/settings`: показать все настройки
- `/set GEMINI_API_KEY AIza…`: поменять ключ (сообщение с ключом бот сразу удалит)
- `/set GEMINI_VOICE Kore`: другой голос (Puck, Charon, Kore, Fenrir, Aoede, Leda, Orus, Zephyr…)
- `/set ASK_TIMEOUT 15`: сколько ждать твоего ответа
- `/set OWNER_NAME Алексей`: от чьего имени звонит бот
- `/set GEMINI_MODEL …`: сменить модель, когда Google выпустит новую
- `/set LIVE_TRANSCRIPT 0`: не присылать реплики вживую, только итог и расшифровку
- Также можно поменять Twilio-ключи, номер и `PUBLIC_URL`.
- `/set КЛЮЧ` без значения возвращает значение из `.env`.

Настройки хранятся в `data/settings.json`.

## Важно знать
- **Честность:** если собеседник прямо спросит, робот ли это, бот скажет, что он ИИ-ассистент, звонящий по твоему поручению.
  В ряде стран закон требует сообщать о записи или ИИ-звонке, так что учитывай местные правила.
- Бот **не называет** номера карт и пароли. Оплату по телефону делай сам.
- Меню автоответчиков вида «нажмите 1» бот пока не нажимает: он только говорит голосом.
  Многие такие меню понимают голос («оператор»), но не все.
- Модели Gemini Live периодически обновляются. Если звонок падает с ошибкой модели, посмотри актуальное имя
  в документации Live API и поставь его через `/set GEMINI_MODEL`.

## Файлы
- `app/main.py`: сервер (FastAPI) и запуск Telegram-бота
- `app/telegram_bot.py`: команды, кнопки, разбор номера
- `app/call_session.py`: сам звонок: мост Twilio ↔ Gemini, инструменты `ask_owner` / `end_call`, промпт
- `app/audio.py`: перекодирование звука (μ-law 8 кГц ↔ PCM 16/24 кГц)
- `app/config.py`: настройки (.env + изменения из Telegram)
- `worker/index.js`, `wrangler.jsonc`: обёртка для Cloudflare Containers
